# Claim wording

Write each claim at the level its evidence supports. If the evidence is between two levels, use the
lower one.

## The ladder

| Evidence | Wording that fits | Wording to avoid |
|---|---|---|
| A computational prediction only | "is predicted to", "candidate" | "is", "identifies", "demonstrates" |
| A statistical association | "is associated with", "correlates with" | "causes", "regulates", "drives" |
| Similarity to a known sequence | "is similar to", "shares a domain with" | "is homologous to" unless shown, "has the function of" |
| Enrichment in a set | "is enriched among", at a stated background | "is involved in" |
| A significant difference after correction | "differs", with effect size and interval | "greatly", "dramatically" without a number |
| Replicated in independent data | "is reproducible in" | "is true" |
| Direct experiment | "shows" | beyond what the experiment tested |

## Words that need a check

| Word | Ask |
|---|---|
| significant | After correcting for how many tests; how large is the effect |
| novel | Compared with which databases and release |
| conserved | Across which species, with what alignment and threshold |
| gene | Or a candidate open reading frame |
| interaction | Physical, genetic, or only correlation |
| validated | By what independent method |
| robust | To which changes in data and parameters |

## Examples

| Draft | Better |
|---|---|
| "We identified 120 new genes." | "We predicted 120 open reading frames of at least 100 codons with no match in the database release used; none has independent support yet." |
| "Gene X regulates Y." | "Expression of X and Y was correlated (r = 0.7, n = 24); the data do not show direction." |
| "The result is highly significant (p < 0.05)." | "The difference was 0.4 (95% interval 0.1 to 0.7), adjusted p = 0.03 across 20,000 tests." |
| "The model is accurate." | "On held-out families the model reached AUROC 0.81; average precision was 0.22 against a chance level of 0.05." |

## Limits paragraph

Name the two or three things most likely to change the conclusion: a design weakness, a data
quality issue, an assumption in the null model. Take them from the review findings, not from a stock
phrase.
