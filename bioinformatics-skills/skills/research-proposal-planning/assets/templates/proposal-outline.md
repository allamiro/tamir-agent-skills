# Proposal or thesis outline

| Section | Content | Done |
|---|---|---|
| Question and type (exploratory or confirmatory) | One sentence, with the prediction if confirmatory | |
| Background and prior work | What exists, the closest competitor, the gap | |
| Aims | Two or three, each with output, success criterion, method, risk, fallback | |
| Preliminary data or feasibility | What shows it can work | |
| Approach | Data, design, analysis plan, controls, validation | |
| Schedule | Tasks, critical path, buffer, decision gates | |
| Risks | Likelihood, effect, early warning, response | |
| Data management and sharing | Checked with `dmpcheck.py` | |
| Ethics, consent and access | Approvals and agreements | |
| Resources | People, compute, storage, money | |
| Roles and credit | Who does what, authorship criteria, contribution roles | |
| Outputs | Papers, software, data, with licences | |
