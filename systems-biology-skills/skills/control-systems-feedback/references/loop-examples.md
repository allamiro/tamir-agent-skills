# Feedback and feed-forward in biology (illustrative)

| Example | Loop | What it does |
|---|---|---|
| End-product inhibition of the first enzyme of a biosynthetic pathway | Negative feedback | Keeps the product level near a set point despite demand changes |
| Autorepression of a transcription factor | Negative feedback | Speeds the response and reduces cell-to-cell variation |
| Mutual repression of two genes (toggle) | Positive feedback (two negatives) | Bistable switch with memory |
| Autoactivation of a cell-fate regulator | Positive feedback | Commitment, hysteresis |
| Activator acting directly and through an intermediate on the same target | Coherent feed-forward loop | Responds only to persistent signals |
| Activator that also induces a repressor of the same target | Incoherent feed-forward loop | Pulse, adaptation |
| Negative feedback with a delay (transcription, transport) | Delayed negative feedback | Oscillation (for example circadian or cell-cycle oscillators) |

These are standard textbook examples given from author knowledge; check the specific system's literature
before using one as evidence.
