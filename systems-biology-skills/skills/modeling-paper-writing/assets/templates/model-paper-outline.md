## Model description checklist

- [ ] Network diagram with all species and reactions
- [ ] All equations, with units
- [ ] Assumption list with justification
- [ ] Parameter table: symbol, meaning, value, unit, source, status (measured, fitted, assumed)
- [ ] Initial conditions
- [ ] Solver, step or tolerances, software versions
- [ ] Fitting: data, objective, starts, identifiability
- [ ] Model file (SBML or CellML) and code with a permanent identifier
- [ ] Simulation description (SED-ML or equivalent), as MIASE asks

## Results as questions

1. Does the model reproduce the training data?
2. Does it predict data not used for fitting?
3. Which parameters drive the conclusions?
4. Do alternative models fit as well?
