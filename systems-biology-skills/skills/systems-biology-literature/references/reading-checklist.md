# Reading a modelling paper

1. **Question.** What observable does the model explain or predict? Is it stated before the model?
2. **Formalism.** Why this one? Was a lighter one considered?
3. **Boundary and assumptions.** Listed? Which would change the conclusion if wrong?
4. **Equations.** Complete, with units? Do they match the model file?
5. **Parameters.** For each: measured, fitted or assumed; source; organism and conditions.
6. **Fitting.** Which data, which objective, how many starts, identifiability checked?
7. **Validation.** On data not used for fitting? A prediction tested experimentally?
8. **Sensitivity and robustness.** Which parameters drive the conclusions?
9. **Alternatives.** Were competing models compared (for example with AICc)?
10. **Availability.** Model file in a standard format, code, data, versions; does it run?
11. **Claims.** Do the conclusions stay within the evidence and the assumptions?
12. **Writing.** Can a reader state the question, the main result and its limit from the abstract alone?

Author knowledge, organised to match the review dimensions in `model-review`.
