# Planning checklist for a modelling project

## Question

- [ ] The question names an observable and a comparison
- [ ] The hypothesis is falsifiable and the refuting result is written down

## Model–experiment cycle

- [ ] First model from existing data, with its assumption register
- [ ] The next experiment chosen by what the model cannot yet decide
- [ ] At least two rounds budgeted

## Measurement (see quantitative-research-methods)

- [ ] Each readout or score has a construct definition and a scoring rule
- [ ] Reliability and validity evidence planned for new readouts
- [ ] Missing-data rule decided
- [ ] Analysis method chosen and justified before data collection

## Design

- [ ] Observability of the states the question needs
- [ ] Perturbations that separate rival models
- [ ] Time points for fast and slow processes
- [ ] Replicates from precision needed (simulation with realistic noise)

## Data and provenance

- [ ] Formats, metadata standards, repositories, licences
- [ ] Model files in SBML or CellML with SED-ML simulation descriptions
- [ ] Provenance records (source, version, processing, agent) for integrated data
- [ ] Code versioned, environment pinned

## Risks

- [ ] For each aim: what could fail and the alternative
- [ ] Aims not chained so that one failure stops all

## Team and ethics

- [ ] Skills across biology, mathematics, computing; training planned
- [ ] Ethics and data protection for human or animal data
