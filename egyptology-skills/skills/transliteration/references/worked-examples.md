# Worked examples

These show the method on spellings whose sign values are in the curated table. They are
illustrations of the steps, not attested citations; check any word against a dictionary before
quoting it (VERIFY).

## 1. A son

Signs: G39 (pintail duck) + A1 (seated man).

1. G39 is a biliteral sꜣ in the table (Gardiner p. 471, which also gives the older reading zꜣ).
2. A1 is a determinative for a man (p. 442): no sound.
3. Transliteration: sꜣ. Gloss to be supplied by `text-annotation`: "son" (the sign-list itself
   uses sꜣ "son" as its example).
4. Flags: none for the sign values; segmentation is clear because the determinative ends the word.

## 2. House, written as an ideogram

Signs: O1 (house) + Z1 (stroke).

1. O1 reads pr as a biliteral and is also a determinative for buildings.
2. Z1 after a sign marks that it means the thing itself (p. 534), so this is the ideogram.
3. Transliteration: pr. A flag is still needed: with no determinative after it, the reading rests
   on the stroke; look for a parallel.

## 3. Ambiguity not to hide

Signs: N5 (sun) alone.

1. N5 is the ideogram rꜥ ("sun, day") and also a determinative for time.
2. Alone, both are possible. List both, choose by context (a word before it with a time sense
   points to a determinative), and mark the choice `uncertain` if context is thin.
