# Review checklist

## Sign layer

- [ ] Every sign has a code, and the code resolves to one Unicode character.
- [ ] Every sign value has a source and a page or entry.
- [ ] Roles are stated (phonogram, ideogram, determinative, marker) and consistent with the word.
- [ ] No consonant is counted twice because of a phonetic complement.
- [ ] Variant forms and starred signs are noted.
- [ ] Damaged or restored signs are separate from certain ones.

## Convention

- [ ] The transliteration convention is named once and used throughout.
- [ ] Brackets mean what the convention says.
- [ ] Gardiner-era spellings are converted or labelled.
- [ ] The period is stated (Old, Middle, Late), and the values fit it.

## Words and translation

- [ ] Word boundaries are justified.
- [ ] Every gloss has a source or is marked VERIFY.
- [ ] The same word is glossed the same way each time, or the difference is explained.
- [ ] Every translated word maps to a row and every row to a word.
- [ ] Gaps are shown as gaps.

## Calibration

- [ ] Each grade A word has a sign source and a dictionary source.
- [ ] No grade rests on "it sounds right".
- [ ] The line grade is the weakest word.

## Data (if the work is a database or app)

- [ ] No duplicate keys; no reading without a status.
- [ ] Sampled records match the page images.
- [ ] Round trips (export and import) lose nothing the model holds.
- [ ] Licences of source data and fonts are recorded.

## Report

- [ ] Findings ranked, each with evidence, impact, fix.
- [ ] "Not checked" section present.
